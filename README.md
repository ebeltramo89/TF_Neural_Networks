# Trabajo Final del curso Redes Neuronales - Famaf UNC
Se construyeron dos redes neuronales convolucionales (empleando PyTorch) que operan sobre el dataset Fashion MNIST. La primera de ellas es un autoencoder y la segunda un clasificador basado en el encoder del autoencoder. Entre otras cosas se aplicaron:
- Un planificador de la tasa de aprendizaje.
- Se evaluaron dos optimizadores, Adam y el SDG.
- Se consideraron diversas funciones de activación, minilotes de entrenamiento, dropout, entre otros.
